# 更新日志

当前版本 **v1.0.5**。下面按版本倒序列出每个版本改了什么。

## v1.0.5 —— 最终版

- 内容与 v1.0.4 **逐字相同**（v1.0.4 之后没有再改代码），只是重出一份作为这一轮的
  最终交付。这一轮的全部内容见下面 v1.0.4 与 v1.0.3 两条：编辑界面重排（参考
  FL Studio 钢琴窗）、两处安全修复、设置即时生效、插入行避让、刻度线更好抓、
  「联网查找字词」改名。

## v1.0.4 —— 编辑界面重排（参考 FL Studio 钢琴窗）· 两处安全修复

**界面**（层级与密度向 FL Studio 靠拢，青绿主色不变）：

- 顶部收成一条细品牌条 + **分组工具条**（导入 ｜ 导出 ｜ 工具），不再是一整块大标题。
- 圆角、留白、字号整体收紧：面板不再是"大圆角卡片"，更像一台风琴窗式的工具。
- 波形刻度线：时间标尺变成一条**带**，网格分三档粗细（细分只在放大时出现）；
  **句首与句尾画得比逐字边界粗**；抓取范围 ±6px → **±8px**；几条挤在一起时抓
  **离鼠标最近**的那条；音符条加高到 38px 并加了描边，字格底色提亮。
- 表格改成致密列表（行距收紧、时间用等宽字体、按钮小一号）。

**安全修复**：

- 波形提示条不再把歌词文本当 HTML 插入。歌词来自联网源或本地文件，字里带
  `<img onerror=…>` 之类的标签时，原来会在程序自己的源里执行脚本。
- `/api/lyric` 只读取 `.lrc` 文件且限 2MB：原来任意本地文件都能读。
- 调试页**默认关闭**：原来那个写死的默认口令 `saltlrc` 已移除，需要设置环境变量
  `SALTLRC_DEBUG_PASSWORD` 才会打开（口令只在本机校验）。

## v1.0.3 —— 设置即时生效 · 插入避让 · 刻度线更好抓

- 设置里改了**不用再点保存**：勾选框与下拉一改就生效，文字框在离开输入框或按回车时生效；
  对话框底部会短暂显示「已保存」。哪一项没存上仍然会红字说明原因。
- 新增 / 插入一行歌词时，新行的位置**不会落进上一行已经唱过的那一段**：上一行写明了句尾，
  新行就排在句尾之后。上下两行之间确实挤不下时，会提示先把上一行的句尾往前收。
- 波形上的刻度线更好认、也更好抓：
  - **句首与句尾画得比逐字边界粗**；
  - 鼠标压在哪一条上，那一条会变得最粗、换个颜色，并在上方多出一个小方块；
  - 抓取范围由 ±6px 放宽到 **±8px**；
  - 同一个位置上有两条时，抓**离鼠标最近**的那条；距离不到 1 像素时按
    「句尾 → 句首 → 逐字」定序，因此同一个位置点两次抓到的永远是同一条。

## v1.0.2 —— 深色 / 浅色主题

- 「设置 → 外观」新增一个开关：**深色模式**（关掉就是浅色主题），点保存后生效。
- 颜色分成两套，界面、波形、表格、对话框与曲库页一起换，不会留下深色斑块。
- 浅色下按可读性调过：正文与次要文字的对比度都够；波形的两条音轨与逐字格子
  在浅底上也分得开。
- 首屏不再闪：程序在画出第一帧之前就按上次的选择定好主题。
- 默认仍是深色，不打开这个开关看不出区别。

## v1.0.1 —— 修：扫码登录后没有反应

- 等待扫码时，程序在一次等待窗口（150 秒）用完后就把界面停在"二维码已过期"上，
  而那个二维码本身仍然有效 —— 扫码并在手机上确认之后没有人再接，登录不会完成。
- 现在把"这一轮等够了"和"码真的失效"分开：等待窗口结束会继续等下一轮，
  只有网易云明确回复该码失效时才提示重新生成。
- 轮询过程中偶发一次网络失败不再中断整次登录；连续三次才报错。

## v1.0.0 —— 正式版

功能与 v0.24.4 相同，本版只把版本号定为 1.0，并明确后续的兼容承诺：

- 歌词文件格式：`[句首]<每字时间>字…<句尾>` + 翻译整行；逐行与逐字可混在同一份文件里；旧文件照常读取。
- 工程文件 `.saltproj`：纯 JSON 与「内嵌音频的容器」两种形态都会继续支持。
- 凭据（网易云登录态、AI 翻译 Key）只存本机，接口只回状态、不回内容。

## v0.24.4 —— `.saltproj` 的图标与双击打开

- 资源管理器里 `.saltproj` 显示本程序图标，双击直接用本程序打开。
- 只写当前用户注册表（`HKCU`，无需管理员权限）；「设置 → 工程文件」里可随时取消。
- 若「打开方式」被指定成别的程序，或指向旧版本的路径，设置里会写明当前状态与原因。

## v0.24.3 —— 修：拖动窗口缩放时界面布局错乱

窗口拖窄到一定程度后，编辑器会被挤成细长一条；原因是分栏宽度与网格断点分别由两套规则决定，
窗口宽度变化时两者不一致。现在网格与断点由样式表统一决定，分栏只提供一个宽度值，
并加上「不超过窗口一半」的上限。

## v0.24.2 —— 逐行与逐字可以混着导出

- 一行没写逐字时，不再让整首降级：有逐字的行按 `[句首]<每字时间>` 写，没有的行按 `[句首]整行` 写。
- 校验分级调整：能照实写出来的问题只作提示；只有「写出来就是坏文件」的才拦下。
- 修：上一版引入的一处崩溃（YRC 导出路径）。

## v0.24.1 —— Salt 逐字格式：逐行用 `[]`，逐字用 `<>`

导出时区分句首与每个字的时间戳（`[句首]` + `<每字时间>` + `<句尾>`），翻译轨不变。
旧文件照常读取，导出 → 读回 → 再导出结果一致。

## v0.24.0 —— 打开 / 编辑 / 保存链路

- 自动保存只处理改动过的那一份文档，队列很长时不再逐条重算。
- 保存工程勾选「内嵌音频」时改为容器格式：音频以原始字节存进 `.saltproj`，不再 base64。
- 音频格式清单归一，导入不支持的格式时直接说明并用什么格式替代。
- 出错分级提示：主动操作失败弹框，后台失败挂横幅。
- 修：同时新建工程时可能丢记录。

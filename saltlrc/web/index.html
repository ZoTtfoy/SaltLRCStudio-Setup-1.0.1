帮助




试听（走带条）


    
      
  • 倍速：走带条上的「倍速」下拉可放慢到 0.25× 或加快到 3×，
      放慢用来听清每个字的起音位置；慢放时按 Enter 打点记录的仍是音频里的真实时间，
      不受倍速影响。选过一次会记住，换歌也不会被重置。
    • 
  
  • 从暂停点继续：按了暂停再按播放，接着刚才的位置继续（不会回到开头）。
      想让每次播放都从头开始，到「设置 → 功能开关」把
      「播放/暂停后再按播放，从暂停点继续」关掉即可。
    • 
  
  • 反复播放（走带条上的「反复」）：打开后，暂停再按播放会跳回
      「这次开始播放的位置」重播 —— 用来反复抠同一句最省事。
      做法：点波形 / 贴条 / 表格某一行把指针放到这一句的开头（任意位置都行），
      按播放听一遍，按暂停，再按播放 —— 又从那句开头开始。
      
    和上面那条的关系：它俩是同一个手势的两种答案，
      所以定了明确优先级：「反复」开着时以它为准，
      「从暂停点继续」不参与判断；关掉「反复」就回到上面那条的行为。
    • 
  
  • 点某一行 / 点波形空白 / 点贴条 = 显式换位置；点过之后按播放就从那里开始
      （这一条不受上面的开关影响，也是「反复播放」重新取起点的方式）。
    • 



快捷键


下面这些都可以在「设置 → 按键绑定」里改成你习惯的组合。


    
  
  • 空格 播放 / 暂停（输入框内不受影响）
    • 
  
  • Enter 逐字编辑器打开时：给下一个字打点（打点模式）
    • 
  
  • Ctrl+Z / Ctrl+Y 撤销 / 重做
    • 
  
  • F1 打开本帮助 · Esc 关闭对话框 / 退出全屏预览
    • 



波形编辑


    
  
  • 按住歌词块横向拖动 = 整句移动（自动贴住相邻句，不会拖过别的行）；松手前会显示落点。
    • 
  
  • 双击歌词块改文字；字数不变会保留逐字时间，字数变化才清除该行逐字轴。
    • 
  
  • 拖动块边缘的竖线微调句首 / 句尾；块内部的竖线调逐字时间。
    • 
  
  • 改逐字时间：鼠标移到某个字上，会显示它是第几个字、字面和时间，
  该行的每个字也会浮出小抓手 —— 看得见才点得准。按住拖动时数字跟着光标走，
  还会显示相对起点移了多少。
    
      
      
    • 字与字的时间必须递增，所以一个字最多只能拖到下一个字之前。
      想把间距拉开，就按住 Alt 再拖：
      这个字和它后面的字会一起往后走（间距不变）。
      • 
      
    • 单击某个字可以选中它，然后用 ← → 微调：
      每按一次 10ms，按住 Shift 是 1ms。
      • 
      
    • 双击某个字的竖线，直接打开逐字编辑器（分词 / 打点 / 均分）。
      • 
    
    
  
    • 
  
  • 滚轮 = 横向平移视窗，Ctrl+滚轮 = 缩放；缩放也能直接输入 px/s。
    • 



整首歌贴条（进度条）


    
  
  • 拖动橙色亮框 = 平移视窗；按住亮框以外拖动 = 直接拖动播放位置。
    • 
  
  • 亮框长度代表「现在能看见整首歌的多少」，只跟缩放有关：拖动它不会改变长度，只是左右平移。
    • 
  
  • 手动平移后自动跟随会暂停（「跟随播放」变淡），播放头走出视窗不再被拉回；点「定位」、点贴条空白处或重新播放即恢复。
    • 
  
  • 底部刻度是整首歌的时间轴，白线（带小三角）是当前播放位置。
    • 



逐字 / 逐词时间


    
  
  • 表格每行的「编辑逐字」打开卡片式编辑器：每个字词一张卡（文字 + 秒数 + 「● 当前」）。
    • 
  
  • 自动分词：按演唱分组切卡（英文整词、汉字+送假名成组、长假名串按 3 切），旧时间按位置继承。
    • 
  
  • 打点模式：勾选后播放音频，每到该字发声就按一次 Enter，打完自动写句尾。
    • 
  
  • 「按字数均分」只是给个参考起点；时间倒退的卡会标红，应用前会做校验。
    • 



加行 / 删行


    
  
  • 顶部 添加行 和表格每行末尾的 ＋插入 是同一个功能，都往下方新增一行空白歌词。
    • 
  
  • 已经选中某一行（点过表格行、点过「定位」或在波形上点过该句）时，新行插在它下面。
    • 
  
  • 没有选中任何行时，新行按当前时间轴插入：播放头（或贴条拖到的位置）落在哪一句里，就插在那句之后。
    • 
  
  • 新行的句首自动取上下两行的中间；两行挨得太近（不足 2 毫秒）时会提示先拉开，不会硬塞一个重叠的行。
    • 



歌词来源


    
  
  • 从曲库导入：挑 Salt Player 里的歌，歌词和音频一起带进来；没有歌词的会自动联网查。
    • 
  
  • 「导入音频」后如果发现没有歌词，会自动按文件名去曲库 / 网易云找，候选列表里手动锚定。
    • 
  
  • 「识别与对齐」页：智能贴唱 —— 一个按钮跑完整首（本机能量分析找人声起点 → 整首一起走一条单调路径 → 先把结果作为可播放的预览叠在波形上，确认贴合了再「应用贴唱」，可撤销）。它只贴整行的句首/句尾，不会伪造时间；逐字的微调在逐字编辑器里用「从音频检测这一行」。
    • 



表格与波形的联动


    
  
  • 播放时表格会自动滚到当前这句（取消勾选「跟随播放」可关掉）。
    • 
  
  • 鼠标划过表格某一行，波形上会高亮那一句；移开鼠标就回到正在播放的句子。
      播放时随便划过表格不会打断高亮跟随。
    • 
  
  • 点表格行、点「▶ 定位」或在波形上点某句，都会把波形滚到那一句并取消鼠标高亮。
    • 



工程文件（.saltproj）


    
  
  • 「保存工程…」生成独有格式 .saltproj，记录歌词、逐字时间、翻译、歌名与时长，并弹出对话框让你选保存位置。
    • 
  
  • 「工程内嵌音频」只作用于保存工程：勾选则音频一起打包（文件约音频的 1.35 倍），打开后歌词 + 波形 + 播放都能恢复；不勾选则文件很小，打开后再补同名音频。
    • 
  
  • 打开工程：点顶部「添加 / 打开歌词 · 音频 · 工程」，或把 .saltproj 直接拖进窗口。
      在「设置 → 工程文件」里关联过之后，在资源管理器里双击 .saltproj 也会用它打开
      （关联只写当前用户的注册表，随时可以在那里撤销）。
    • 



写入与导出


    
  
  • 「导出歌词…」把当前这首歌另存为 LRC / YRC：只写歌词，不写音频，并弹出对话框让你选保存位置。
    • 
  
  • 「批量导出 ZIP」把队列中通过检查的歌打成一个压缩包。
    • 
  
  • 要直接写进歌曲目录并批量处理，用右上角的「联网查找字词」。
    • 
  
  • 主歌词逐字时间戳 + 句尾；翻译整行、与主句同句首 —— 这是 Salt Player 的规则。
    •
